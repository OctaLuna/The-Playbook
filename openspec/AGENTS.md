# OpenSpec Instructions

> **Nota:** este archivo normalmente lo genera y mantiene el CLI oficial (`openspec init` / `openspec update`), que lo adapta a las herramientas de IA instaladas en el proyecto. Este es un placeholder mínimo para que la carpeta `openspec/` esté completa mientras tanto — reemplázalo corriendo `openspec init` o `openspec update` en un entorno con el CLI instalado.

Instrucciones para asistentes de IA trabajando en este proyecto:
- Antes de proponer o implementar un cambio, lee `openspec/project.md` para el stack y las convenciones no negociables.
- Cada feature nueva es un `change` en `openspec/changes/<id>/` con `proposal.md`, `design.md`, `tasks.md` y `specs/<capability>/spec.md`.
- No escribas código de implementación sin que exista primero un `proposal.md` aprobado.
- Al completar un change, se archiva y sus specs delta se fusionan a `openspec/specs/`.
