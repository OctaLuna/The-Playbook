## Puede adelantarse sin esperar

Nada de este sprint depende de nadie más que de sí mismo — es, por diseño, un sprint de cierre
y refuerzo, no de features nuevas.

## Riesgos y dependencias

- Si algún track llegó a este sprint con deuda pendiente (una prueba de integración saltada, un
  caso límite sin cubrir), este es el momento de pagarla — el Sprint 8 es para regresión y
  entrega, no para terminar features.
- La accesibilidad (Grupo 6 de `004`) es la única tarea con fecha dura de este sprint — si Carol
  necesita ayuda, es el momento en que Rodrigo/Leandro/Einar tienen holgura real para dársela.

## Definition of Sprint Done

- `004` cumple la DoD completa de `docs/team-charter.md` §6, incluida accesibilidad AA.
- Las 4 features están marcadas Done en ClickUp con su evidencia enlazada.
- Un recorrido manual completo (lista → filtro → ficha → explicación → pregunta de seguimiento →
  panel de track record) funciona sin errores, con datos reales.
